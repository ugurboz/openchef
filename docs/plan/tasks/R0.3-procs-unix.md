# R0.3 — `openchef-procs`: public API and macOS/Linux supervision

| Owner | Milestone | Depends on | Size |
|---|---|---|---|
| Lead | R0 | R0.1 | L |

## Goal

Leak-free child process supervision (§5.1): start a child with pipes in its own process
group, terminate gracefully then forcefully, kill the whole tree, identify processes by
PID + start token so a later daemon can kill leftovers safely. Defines the public API
that R0.4 implements for Windows.

## Read first

`docs/architecture.md` §5; D-019. Go: `internal/procs/procs.go`, `procs_unix.go`,
`procs_darwin.go`, `procs_linux.go`, all tests and `helper_unix_test.go`.

## Scope

`crates/openchef-procs/**` (Unix modules, shared API, test helper binary)

## What to build

- `Spec { program, args, dir, env, stdin/stdout/stderr: Pipe|Null|Inherit }`.
- `Process::start(spec) -> Result<Process>`; `identity() -> Identity { pid, start_token }`;
  `wait()`; `terminate(grace, cancel)` (close stdin → SIGTERM to group → SIGKILL after
  grace; a cancelled token skips grace); `close()` idempotent; `Drop` kills the group.
- `alive(&Identity)`, `kill_if_alive(&Identity)` comparing the start token
  (macOS: `proc_pidinfo` start time; Linux: `/proc/<pid>/stat` field 22).
- Linux: `PR_SET_PDEATHSIG(SIGTERM)` in `pre_exec`; process group via `setpgid`.
- A test helper binary (`[[bin]]` behind a `test-helper` feature) replacing the Go
  `TestMain` re-exec trick: echo, ignore-stdin, ignore-SIGTERM, spawn-grandchild modes.
