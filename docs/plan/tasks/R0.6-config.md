# R0.6 — `openchef-config`: TOML config, paths, validation

| Owner | Milestone | Depends on | Size |
|---|---|---|---|
| **Uğur** | R0 | R0.1 merged | M |

## Goal

Load, validate and write `~/.openchef/config.toml` (pools, agents, routing, quota) with
the exact keys and rules of the Go implementation, plus the OpenChef home and path
helpers every other crate uses.

## Read first

- `AGENTS.md`, `docs/architecture.md` §7.3, §7.4, §10.2, §13.
- Go reference (`../openchef-go`): `internal/config/config.go`, `defaults.go`,
  `paths.go`, `config_test.go`.

## Scope

`crates/openchef-config/**`

## What to build

1. **Types** with `serde` + `toml`: `Config { pools, agents, routing, quota }`, `Pool`,
   `Agent`, `Phase`, `Quota`. Every Go string list (`Providers`, `Billings`,
   `PlanTiers`, `EffortProfiles`, `Runtimes`, `Tiers`, `Efforts`, `Strategies`,
   `Phases`) becomes a Rust `enum` with `#[serde(rename_all = "…")]` so an unknown value
   is a parse error with the file, line and the allowed values.
2. **Validation** exactly as Go: agents reference existing pools, routing references
   existing agents, weights only with `weighted`, budgets only on API pools, etc. Return
   *all* problems at once (`Error::Invalid(Vec<Problem>)`), each with a TOML path like
   `agents.opus.pool`.
3. **Defaults** (`defaults.go`) and `Quota::probes_enabled(provider)`.
4. **Paths** (`paths.go`): home = `OPENCHEF_HOME` or `~/.openchef` on every OS;
   `config_path`, `state_db_path`, `sessions_dir`, `worktrees_dir`, `logs_dir`,
   `daemon_lock`, `daemon_socket`. Directories created with mode 0700 on Unix.
5. **Write:** `Config::save(path)` writes atomically (temp file + rename) with stable
   key order, so `init` can create the file.

## Acceptance criteria

- [ ] Every case in `config_test.go` ported and passing on 3 OSes.
- [ ] An invalid file reports every problem with its TOML path (snapshot test with `insta`).
- [ ] Round trip: load → save → load gives an equal `Config`.
- [ ] Local gate clean.

## Out of scope

Permission settings files (`settings.toml`, R4.1), `init`/`doctor` commands (R0.7).
