## Goal

Everything every other card builds on: a compiling workspace with one empty crate per
§16 entry, the lint set of D-030, CI on Linux/macOS/Windows, dependency policy, and the
issue/PR templates. Blocks every other code card.

## Read first

`docs/architecture.md` §16, §18; D-027, D-030; `AGENTS.md`.

## Scope

- `Cargo.toml`, `Cargo.lock`, `rust-toolchain.toml`, `deny.toml`, `.gitignore`,
  `.editorconfig`, `rustfmt.toml`, `clippy.toml`
- `crates/*/Cargo.toml`, `crates/*/src/lib.rs` (crate doc only), `crates/openchef-cli/src/main.rs`
- `.github/workflows/ci.yml`, `.github/workflows/stress.yml`,
  `.github/pull_request_template.md`, `.github/ISSUE_TEMPLATE/task.md`, `.github/CODEOWNERS`
- `README.md`, `CONTRIBUTING.md` (points to `AGENTS.md` and `docs/plan/team.md`)

## What to build

- Edition 2024, stable toolchain pinned with `rustfmt`, `clippy` components.
- `[workspace.dependencies]` for every intended crate of §16 (exact versions), crates
  opt in with `workspace = true`.
- `[workspace.lints]` exactly as D-030; `openchef-procs` and `openchef-sandbox` override
  `unsafe_code = "allow"` with a comment. Tests allowed `unwrap`/`expect` via
  `clippy.toml` (`allow-unwrap-in-tests`, `allow-expect-in-tests`).
- `deny.toml`: advisories deny, licenses allowlist compatible with Apache-2.0, bans
  for duplicate major versions warn, sources crates.io only.
- CI (`ci.yml`): fmt + clippy + deny + doc on Ubuntu; build + nextest on the 3-OS
  matrix with `Swatinem/rust-cache`; actions pinned by SHA; `permissions: contents: read`.
- `stress.yml`: `workflow_dispatch(count)` and PRs touching `procs`, `store`,
  `runtime`, `engine`, `daemon`, `sandbox`; runs `cargo nextest run` repeated `count`
  times on 3 OSes.
- `openchef-cli` builds an `openchef` binary that prints its version.
- Branch protection on `main` (after the first push): required checks, 1 review,
  up-to-date branches, no force pushes.

## Acceptance criteria

- [ ] `cargo build --workspace` and the full local gate pass on all three OSes in CI.
- [ ] A deliberate `unwrap()` in a non-test file fails clippy (checked once, not committed).
- [ ] Issue template contains the card sections; PR template contains the checklist from `AGENTS.md` §8.
